## Overview

BillingGuru is a powerful, feature-rich Point of Sale application designed for small to medium-sized retail businesses. It provides comprehensive billing, inventory management, sales tracking, and reporting capabilities.

### Key Features

- **Fast Billing** - Quick and intuitive billing interface with barcode scanning
- **Inventory Management** - Track products, stock levels, and categories
- **Sales Analytics** - Real-time sales reports and performance metrics
- **Receipt Printing** - Professional receipt generation with customizable templates
- **Tax Management** - Built-in tax calculation and configuration
- **Multiple Payment Methods** - Support for various payment types
- **Sales History** - Complete transaction history with reprint functionality
- **Dashboard** - Real-time business metrics and insights

### System Requirements

- **Flutter SDK**: ^3.13.2
- **Dart SDK**: Latest stable version
- **Platform**: Windows, iOS, Android, Web (with platform-specific support)
- **Database**: SQLite

### Technology Stack

- **Framework**: Flutter 3.x
- **State Management**: Riverpod
- **Navigation**: GoRouter
- **Database**: SQLite with sqflite
- **PDF/Printing**: pdf package with printing integration
- **Barcode Scanning**: mobile_scanner
- **Charts**: fl_chart for analytics visualization
