## Dashboard

The Dashboard is your home screen showing key business metrics and quick access to features.

### Dashboard Features

- **Today's Sales Summary**
  - Total sales amount
  - Number of transactions
  - Average transaction value

- **Quick Stats**
  - Total revenue
  - Top products
  - Inventory alerts

- **Quick Access Buttons**
  - New Sale
  - View Inventory
  - Reports
  - Settings

### Reading the Dashboard

- **Revenue Cards**: Show current day's sales and period totals
- **Charts**: Visual representation of sales trends
- **Alerts**: Inventory warnings (low stock items)

## Main Billing Screen

The billing screen is where you create sales transactions.

### How to Create a Sale

#### Step 1: Add Products
1. Click "New Sale" from dashboard or main menu
2. Use the search bar to find products by name or code
3. Scan barcode using your scanner (if available)
4. Click product to add to cart

#### Step 2: Adjust Quantities
1. Products appear in the cart on the right
2. Click quantity field to edit
3. Use +/- buttons to increase/decrease quantity
4. Set correct amount for each item

#### Step 3: Apply Discounts (Optional)
1. Select a product in cart
2. Click "Discount" button
3. Enter discount amount (percentage or fixed)
4. Confirm discount

#### Step 4: Review Totals
- Subtotal: Sum of all item prices
- Tax: Calculated based on tax rate
- **Total**: Final amount due

### Search and Filter

**Product Search**:
- Type product name or code
- Results update in real-time
- Click product to add to cart

**Categories**:
- Filter by product category
- Shows only items in selected category
- Click "All" to show everything

**Barcode Scanning**:
- Enable camera/scanner
- Point at product barcode
- Item automatically added to cart

## Shopping Cart

The shopping cart displays all items in current transaction.

### Cart Operations

#### Modify Items
- **Quantity**: Click quantity to edit, use +/- to adjust
- **Remove**: Click delete/trash icon to remove item
- **Discount**: Apply item-level discount if allowed

#### Cart Totals
- **Subtotal**: Sum before tax
- **Tax**: Amount calculated on subtotal
- **Total**: Final amount to charge

#### Clear Cart
- Click "Clear All" to remove all items
- Confirm action in dialog
- Starts fresh transaction

### Cart Persistence

- Cart data saved temporarily during transaction
- Cleared after payment is completed
- Can be recovered if payment is cancelled

## Checkout & Payment

Process payments and complete sales transactions.

### Checkout Flow

#### Step 1: Review Order
- Confirm all items in cart
- Verify quantities and prices
- Check applied discounts

#### Step 2: Select Payment Method
Payment methods supported:
- **Cash**: Physical currency payment
- **Card**: Credit/debit card
- **UPI/Mobile**: Digital wallet or mobile payment
- **Check**: Cheque payment
- **Other**: Custom payment types

#### Step 3: Enter Payment Details
- **Amount Received**: How much customer paid
- **Payment Method**: Select from available options
- **Reference**: Transaction ID or check number (if applicable)

#### Step 4: Process Payment
1. Review payment summary
2. Click "Complete Payment"
3. Specify amount if different from total
4. Confirm final amount

#### Step 5: Receipt
1. Receipt automatically generated
2. Options:
   - **Print Receipt**: Send to connected printer
   - **Save Receipt**: Store receipt details
   - **Email Receipt**: Send to customer (if email available)
3. Transaction complete

### Payment Confirmation
- Order number/ID generated
- Timestamp recorded
- Payment status updated to "Completed"
- Customer receipt printed/saved

## Inventory Management

Manage your product catalog and stock levels.

### Viewing Inventory

1. Navigate to **Inventory** from main menu
2. See all products with:
   - Product name and code
   - Category
   - Current stock level
   - Unit price
   - Status (In Stock / Low / Out of Stock)

### Adding Products

1. Click **"Add New Product"** button
2. Enter product details:
   - **Name**: Product name (required)
   - **Category**: Select or create category
   - **SKU/Code**: Unique product identifier (barcode)
   - **Price**: Selling price
   - **Cost**: Purchase/cost price
   - **Stock Quantity**: Current stock amount
   - **Description**: Optional details

3. Click **"Save Product"**
4. Product now appears in billing screen

### Editing Products

1. Click product in inventory list
2. Modify details:
   - Name, price, cost
   - Category, SKU
   - Stock quantity
   - Status

3. Click **"Save Changes"**

### Managing Stock

#### Add Stock
1. Select product
2. Click **"Add Stock"**
3. Enter quantity to add
4. Confirm action

#### Adjust Stock
1. Click **"Adjust Stock"**
2. Enter new quantity
3. Add reason (received, damaged, correction, etc.)
4. Confirm

#### Low Stock Alerts
- Products with stock < threshold show warning
- Configure threshold in Settings
- Dashboard displays alert summary

### Categories

#### Create Category
1. Go to **Inventory > Categories**
2. Click **"Add Category"**
3. Enter category name
4. Click **"Save"**

#### View Category Items
1. Click category name
2. Shows all products in category
3. Edit or delete categories as needed

## Sales Management

Track and manage all sales transactions.

### Sales History

1. Navigate to **Sales** from main menu
2. View list of all completed transactions:
   - Transaction ID
   - Date and time
   - Customer name (if available)
   - Total amount
   - Payment method
   - Status

### Filtering Sales

- **By Date**: Select date range
- **By Payment Method**: Filter by cash/card/other
- **By Amount**: Show sales above/below amount
- **By Status**: Completed/Cancelled/Pending

### Transaction Details

Click any transaction to view:
- Complete item list with quantities and prices
- Tax calculation details
- Discounts applied
- Payment method and amount
- Timestamp
- Receipt (if available)

### Reprint Receipt

1. Find transaction in sales history
2. Click transaction or **"Reprint Receipt"** button
3. Select printer or save option
4. Confirm action
5. Receipt reprinted

### Return/Refund

For refund operations (if supported):
1. Find original transaction
2. Click **"Process Return"**
3. Select items to return
4. Confirm refund amount
5. Process payment back to customer
6. Generate return receipt

5. Confirm export

## Settings

Configure BillingGuru for your business needs.

### Business Details

1. Go to **Settings > Business Information**
2. Configure:
   - **Business Name**: Your company name
   - **Business Address**: Full address
   - **Tax ID/GST Number**: Registration number
   - **Phone**: Contact number
   - **Email**: Business email
   - **Website**: Web address (optional)
   - **Logo**: Upload business logo

3. Click **"Save"**

### Tax Configuration

1. Go to **Settings > Tax**
2. Set default tax rate:
   - **Tax Rate %**: Percentage applied to sales
   - **Tax Name**: e.g., "GST", "Sales Tax", "VAT"
3. Configure by category:
   - Different rates for different product categories
   - Enable/disable tax for specific items
4. Click **"Save"**

### Currency Settings

1. Go to **Settings > Currency**
2. Select currency:
   - Symbol ($, €, ₹, etc.)
   - Decimal places
   - Thousand separators
3. Click **"Save"**

### Financial Year

1. Go to **Settings > Financial Year**
2. Set start date (e.g., April 1, July 1, January 1)
3. Used for period-based reports
4. Click **"Save"**

### Receipt Template

1. Go to **Settings > Receipt**
2. Configure receipt:
   - **Header Text**: Message at top of receipt
   - **Footer Text**: Message at bottom
   - **Business Details**: Show name, address, etc.
   - **Include Logo**: Display business logo
   - **Paper Width**: Set receipt width (for thermal printers)
   - **Font Size**: Adjust text size

3. Preview receipt format
4. Click **"Save"**

### Payment Methods

1. Go to **Settings > Payment Methods**
2. Enable/disable payment types:
   - Cash
   - Card
   - Mobile/UPI
   - Check
   - Other custom methods

3. Configure details for each:
   - Acceptance rules
   - Commission/fees
   - Processing notes

4. Click **"Save"**

### Printer Settings

1. Go to **Settings > Printer**
2. Configure:
   - **Default Printer**: Select connected printer
   - **Paper Size**: A4, thermal, custom
   - **Auto Print**: Print receipt automatically
   - **Print Quality**: Draft/Normal/High

3. Test printer connection
4. Click **"Save"**

### Backup & Reset

1. Go to **Settings > Data**
2. **Backup**:
   - Click "Create Backup"
   - Save backup file to external location
   - Date-stamped file created

3. **Restore**:
   - Click "Restore from Backup"
   - Select backup file
   - Confirm data will be replaced

4. **Reset Application**:
   - Clear all data (WARNING: irreversible)
   - Reset to factory defaults

### App Preferences

1. Go to **Settings > Preferences**
2. Configure:
   - **Theme**: Light/Dark/Auto
   - **Language**: Select language
   - **Notification**: Enable/disable alerts
   - **Auto-logout**: Inactivity timeout

## Tips & Best Practices

### Quick Billing Tips
- Use barcode scanner for faster item entry
- Set up frequently used discounts as presets
- Keep daily backup to prevent data loss
- Review daily sales summary before closing

### Inventory Management
- Regularly update stock counts
- Set appropriate low-stock thresholds
- Archive old/discontinued products
- Use categories to organize products

### Reports & Analysis
- Generate daily sales report before closing
- Review weekly performance trends
- Use reports for pricing decisions
- Track payment method preferences

### Security & Data
- Regularly backup data
- Use strong passwords in settings
- Keep receipt templates updated
- Maintain accurate business information
